Import or export assets

Export saves every asset to a spreadsheet (.csv) that opens in Excel. Import reads a spreadsheet in the same layout. New rows become new assets (leave Tag blank to have them numbered). Rows whose tag is already here update that asset's details. Status, location and loans are never changed by an import. You'll see a summary to confirm before anything is saved.
